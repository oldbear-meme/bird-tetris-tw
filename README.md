# 🐦 小鳥俄羅斯方塊 Bird Tetris

一個以台灣常見鳥類為主題的俄羅斯方塊小遊戲，純 HTML5 Canvas + JavaScript 製作，**單一檔案、免安裝、可離線遊玩**。

## ▶️ 立即遊玩

- **線上版（中文）**：https://oldbear-meme.github.io/bird-tetris-tw/
- **English version**: https://oldbear-meme.github.io/bird-tetris-tw/en/
- **本機版**：下載後雙擊 `index.html`（或 `點我玩.vbs`）即可用瀏覽器開始。

## 🎮 操作方式

| 按鍵 | 功能 |
|------|------|
| `←` `→` | 左右移動 |
| `↑` / `X` | 旋轉（單鈕循環） |
| `↓` / `空白` | 直接落下 |
| `P` | 暫停 |

手機可使用畫面下方的觸控按鈕。

## 🐤 角色與生態玩法

主角是三種台灣常見小鳥，組成掉落的方塊，排滿一整列即消除：

- **白頭翁**：黑頭配明顯白色後頸斑、橄欖綠背、白腹。
- **麻雀**：栗褐色頭頂、白臉頰上有黑斑。
- **綠繡眼**：黃綠身體 + 醒目白色眼圈。

並融入鳥類生態的趣味互動：

- **蚯蚓** 🪱：長在堆疊表面，消除含蚯蚓的列可獲得大量分數。
- **大笨鳥**：圓胖笨拙、慢慢找蚯蚓吃，容易被你搶先。
- **黑領椋鳥**：白頭黑頸環，移動超快會搶先吃掉蚯蚓，製造緊張感。
- **台灣藍鵲**：黑頭紅嘴、超長藍尾，偶爾飛過叼走表面的幼鳥，留下缺口。
